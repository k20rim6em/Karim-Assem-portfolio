## Overview

A university team project (20 students, Zewail City) to design a working 8-bit processor — the "ARM-1" — from individual logic gates up to a full stored-program computer, simulated entirely in Logisim.

## What we built

- A multi-cycle datapath: Program Counter, unified 16×8 instruction/data memory, Instruction Register, B register, ALU, Accumulator, and Output register
- A hardwired control unit — a 3-state ring counter (Fetch/Decode/Execute) plus a combinational instruction decoder
- A 6-instruction instruction set (`LDA`, `ADD`, `SUB`, `STR`, `OUT`, `HLT`) with a 4-bit opcode and 4-bit memory address
- Careful timing logic to avoid bus conflicts and race conditions between memory reads/writes and register latching

## Result

The processor correctly fetches, decodes, and executes programs in exactly 3 clock cycles per instruction, verified end-to-end in Logisim — including a full run of a load/add/output/halt program. A solid hands-on introduction to how the fetch-decode-execute cycle that underlies every modern CPU actually works in hardware.

**Tools:** Logisim, digital logic design, finite-state machines

**Team:** 20-person team project, Communications & Information Engineering Dept., Zewail City (Instructor: Prof. Elmahdy Maree)
