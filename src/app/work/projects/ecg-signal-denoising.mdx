## Overview

Real ECG recordings picked up for remote/telemedicine use are corrupted by baseline wander, 50 Hz power-line hum, and muscle noise — all of which can obscure the waveform features doctors rely on. This project (CIE 247, Digital Signal Processing) designs a three-stage digital filter cascade to clean ECG signals from the MIT-BIH Arrhythmia Database without distorting the clinically important QRS complex.

## What I built

- An FIR high-pass filter (Hamming window, order 800) to remove baseline wander below 0.5 Hz
- An IIR notch filter to sharply cut the 50 Hz mains interference
- IIR Butterworth and Chebyshev Type I low-pass filters to compare noise suppression above 100 Hz
- Zero-phase (`filtfilt`) processing throughout, so filtering never shifts or distorts the waveform in time
- A custom decoder for the MIT-BIH binary (Format-212) ECG files, straight from the raw database

## Result

The full cascade improved the signal-to-noise ratio by roughly 27 dB (from 4.7 dB to 31.6 dB) on a real ECG recording, fully removing the 50 Hz hum and baseline drift while preserving the QRS/T-wave shapes needed for diagnosis. Verified on a second, pathological recording (irregular heartbeats) to confirm the filters don't distort abnormal — clinically important — waveforms either.

**Tools:** MATLAB, digital filter design (FIR/IIR), MIT-BIH PhysioNet database
